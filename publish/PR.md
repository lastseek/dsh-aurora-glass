# 标题
Add dsh-aurora-glass (theme)

# 正文
A dark glass skin for DeepSeek Harness.

- One translucent sheet: sidebar, content and title strip share the same wallpaper,
  opacity and blur, so the window reads as a single pane of frosted glass.
- Settings section「极光玻璃 / Aurora Glass」: pick any image as the wallpaper
  (downscaled to 1920px and stored locally), tune window opacity, blur and reset.
- Purely presentational: no host-side code, no network requests, no extra runtime deps.
- Works with the desktop shell: the native caption buttons are made transparent so
  they float on the glass, and the Windows menu is shifted to the window edge.

Repo: https://github.com/lastseek/dsh-aurora-glass
